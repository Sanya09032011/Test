# Бренд-лук

Повний опис і промпти — `docs/BRAND-LOOK.md`. Референси — `docs/REFERENCES.md`.

## Дизайн-система
1. Спитай назву каналу, нік, соцмережі; є логотип/фото — `node scripts/palette.mjs "<картинка>"`.
2. Покажи вітрини (папка `ДЕМО/`: `ДЕМО-шрифти.png`, `ДЕМО-субтитри.mp4`, `ДЕМО-фони.mp4`) — хай вибере шрифт, стиль субтитрів, фон.
3. Впиши в `studio/src/config.ts` (channel, handle, accent, accent2, ink, paper, font, socials, mascot). Обраний стиль субтитрів і фон запамʼятай для наступних роликів —
   допиши рядок у розділ «Мій стиль» внизу `CLAUDE.md` (і `AGENTS.md`).
4. `npm run demos` → покажи, як стало.

## Персонаж і стікери
- Дай людині промпти з `docs/BRAND-LOOK.md` (картка персонажа → стиль → сітка 3×3 стікерів на зеленому #00FF00) для безкоштовних генераторів (ChatGPT, Google AI Studio, Google Flow, Qwen).
- Готові картинки — у `ЗАНЕСИ-СЮДИ/2…` → `node scripts/stickers.mjs "<файл>" --grid 3x3 --name <імʼя>` → перевір результат (Read PNG) → покажи людині.
- Найкращий стікер — у `config.ts → mascot` (обкладинка й фінальна картка).

## Референси
`ЗАНЕСИ-СЮДИ/3…` → `node scripts/sheet.mjs "<відео>"` + `palette.mjs` → підбери найближчі стиль субтитрів, шрифт, фон, темп, переходи → коротко поясни людині, що взято.
