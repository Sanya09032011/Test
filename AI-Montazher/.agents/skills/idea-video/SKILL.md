# Ролик з ідеї

Повний порядок — `docs/IDEA-VIDEO.md`. Озвучка — `docs/VOICE.md`. Монтажний лист — `docs/EDIT-JSON.md`.

## Коротко
1. Уточни одним повідомленням (якщо не сказано): для кого, головна думка, заклик, тривалість.
2. `node scripts/new.mjs <назва>` → напиши `script.json` (`lines` з тегами `[excited]`, `[confident]`, `[warm]`…; хук-біль → 2–4 кроки → заклик).
3. `node scripts/check-text.mjs <проєкт>` (без латиниці, цифр, тире, апострофів) → `node scripts/tts.mjs <проєкт>`.
4. Перевір вимову: `node scripts/stt.mjs <проєкт> media/voice.mp3`; неправильний наголос → `library/voice/lexicon.json` і перегенеруй.
5. `node scripts/edit.mjs <проєкт> --style <стиль>` → фон під тему → події щільно (кожні 1.5–3 с, перша — в перші 1.5 с).
6. `node scripts/render.mjs <проєкт> --draft` → Read `sheet.jpg` → виправ → фінал `node scripts/render.mjs <проєкт>`.
7. Відкрий людині MP4 і дай опис для соцмереж.

Факти — тільки від людини або з її матеріалів у `ЗАНЕСИ-СЮДИ/4…`. Сумнівне — спитай, не вигадуй.
