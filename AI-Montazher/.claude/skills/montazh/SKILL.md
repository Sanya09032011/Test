# Монтаж запису

Повний порядок — `docs/MONTAGE.md`. Монтажний лист — `docs/EDIT-JSON.md`, анімації — `docs/ANIMATIONS.md`, субтитри — `docs/SUBTITLES.md`.

## Коротко
1. `node scripts/new.mjs <назва>` → `node scripts/prepare.mjs <проєкт> "<відео>"` → `node scripts/stt.mjs <проєкт>`.
2. Прочитай `transcript.json`. Зіпсовані дублі → `drops.json` (`[[початок, кінець]]`, секунди оригіналу; лишається ОСТАННІЙ вдалий варіант).
3. `node scripts/cut.mjs <проєкт>` (паузи + «е/м-м» + дублі) → перевір стики `node scripts/stt.mjs <проєкт> media/cut.mp4`.
4. `node scripts/edit.mjs <проєкт> --style <стиль людини>` → допиши `events`, `keywords`, `transitions`, `cover` за змістом.
5. `node scripts/render.mjs <проєкт> --draft` → Read `sheet.jpg` → виправ → `node scripts/render.mjs <проєкт>`.
6. Відкрий людині MP4; скажи, що вирізано й додано; дай опис для соцмереж; перенеси вихідники з ЗАНЕСИ-СЮДИ/1 у `projects/<проєкт>/inbox/`.

## Що робить ролик цікавим (а не «нудна говоряща голова»)
- У перші 2–3 с — подія (лічильник, `title`, логотип) + `zoom` на першій зміні думки.
- Кожне число, перелік, назва сервісу, порівняння, емоція — графіка на СВОЄМУ слові. Нова подія кожні 2–4 с.
- На екрані одночасно: субтитр + максимум один елемент. Великі вставки — 2–3 с, потім знову обличчя.
- Нічого на обличчі: двигун ставить дрібні елементи нижче обличчя; свої `pos` — збоку або внизу.
- Наприкінці — `subscribe` на словах заклику + `end` (фінальна картка).
