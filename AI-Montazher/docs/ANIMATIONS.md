# Анімації, події й фони

Подивитися все в русі: `ДЕМО/ДЕМО-анімації.mp4`, `ДЕМО/ДЕМО-фони.mp4` (своїми кольорами — `npm run demos` у папці `studio` → `studio/out/`).
Кожна подія в `edit.json → events`: `{ "type": "...", "at": <секунда>, "dur": <скільки триває, с> , ...поля }`.
`dur` можна не писати: дрібні — 1.8 с, великі — 2.6 с.

## 10 бонусних анімацій
| type | Що робить | Поля |
|---|---|---|
| `lowerThird` | плашка з іменем і роллю внизу зліва | `name`, `role` |
| `title` | велике слово з кольоровою смугою (головна думка, назва розділу) | `text`, `sub`, `upper` (false — без капсу) |
| `counter` | число накручується | `from`, `to`, `prefix`, `suffix` (" ₴", "%", "K"), `decimals`, `label` |
| `callout` | стрілка-виноска малюється до точки | `x`, `y` (0…1 від ширини/висоти кадру), `text`, `side` ("left"/"right"), `below` (true — підпис під точкою) |
| `list` | список з галочками, пункти по черзі | `title`, `items: []`, `times: []` (секунда кожного пункту) |
| `steps` | кроки 1-2-3 з лінією прогресу | `title`, `items: []`, `times: []` |
| `chart` | стовпчики ростуть, найбільший — акцентом | `title`, `bars: [{ "label": "Січ", "value": 12 }]`, `suffix` |
| `compare` | було / стало (✗ і ✓), «VS» | `left: { "title", "items": [] }`, `right: { … }` |
| `notification` | пуш-сповіщення падає зверху | `app`, `title`, `text`, `icon` (напр. `social/instagram-colorful-3d-tile.jpg`) |
| `subscribe` | кнопка «Підписатися», курсор клікає, дзвіночок | `text`, `done` (напис після кліку) |

Великі (`title`, `counter`, `list`, `steps`, `chart`, `compare`, `image` у рамці) — запис під ними тьмяніє й розмивається, голос звучить далі.
Дрібні стікери/іконки самі ховаються, коли починається велика вставка.

## Дрібні події
| type | Що | Поля |
|---|---|---|
| `sticker` | стікер людини (`studio/public/stickers`) | `src`, `pos`, `size`, `rot` |
| `icon` | 3D-іконка (230 шт: `studio/public/assets/fl-<назва>.png`, напр. `fire`, `rocket`, `money_bag`, `light_bulb`, `red_heart`) | `name`, `pos`, `size` |
| `logo` | логотип сервісу на білій плитці | `src` (`logos/openai.svg`), `label`, `pos`, `size` |
| `burst` | феєрверк з іконок (перемога, «вау») | `name` (іконка), `count`, `pos` |
| `image` | свій кадр/відео: на весь екран (`full: true`, за замовчуванням) або в рамці (`full: false`) | `src` (`media/…`), `from` (с, для відео), `sound` (true — зі звуком) |

`pos`: `left` · `right` · `center` · `top-left` · `top-right` · `bottom-left` · `bottom-right` або `[x, y]` у пікселях кадру 720×1280.
У записі людини (`fit: "cover"`) позиції автоматично зсуваються нижче обличчя.

## Переходи (`transitions`)
`zoom` — ривок-наїзд з розмиттям · `whip` — свайп убік · `flash` — білий спалах · `shake` — тряска · `blur` — розмиття.
`{ "at": 12.4, "type": "whip" }` — ставити на зміну думки, 1 на 5–8 секунд.

## 10 фонів (`background`)
| назва | вигляд і для чого |
|---|---|
| `grid` | світлий папір у клітинку — експертні, освітні |
| `dots` | крапкова сітка — технології, огляди |
| `gradient` | градієнт кольорами бренду — лайфстайл, beauty |
| `blobs` | розмиті кольорові плями — сучасний «скляний» вигляд |
| `stripes` | діагональні смуги — динаміка, анонси, розпродажі |
| `spotlight` | темна сцена з прожектором — драма, секрети |
| `waves` | хвилі-лінії — спокій, музика |
| `bokeh` | розмиті вогники — свято, вечір |
| `rays` | промені — WOW-момент, перемога (також тло обкладинки) |
| `neon` | неонова сітка 80-х — ігри, AI, ретро |
