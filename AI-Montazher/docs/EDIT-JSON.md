# edit.json — монтажний лист ролика

Один файл описує весь ролик. Його створює `node scripts/edit.mjs <проєкт>` (основа, слова, субтитри, музика),
а агент дописує **події**, **ключові слова**, **переходи** й **обкладинку**. Рендер — `node scripts/render.mjs <проєкт> [--draft]`.

**Усі часи — у секундах від початку ролика** (без обкладинки). Час події = `start` потрібного слова з
`cut_transcript.json` (монтаж запису) або `voice.json` (ролик з озвучкою).
Шляхи до файлів: `media/...` — з папки проєкту; `stickers/…`, `logos/…`, `assets/fl-…png`, `music/…`, `social/…` — з `studio/public`.

## Поля
| Поле | Що це | Приклад |
|---|---|---|
| `format` | `"9x16"` (Reels/TikTok/Shorts) або `"16x9"` (YouTube) | `"9x16"` |
| `base` | основа: запис `{ "kind": "video", "src": "media/cut.mp4", "fit": "cover", "zoom": true, "segments": [...] }` або озвучка `{ "kind": "voice", "src": "media/voice.mp3" }` | — |
| `base.fit` | `"cover"` — запис на весь кадр (говоряща голова); `"card"` — у рамці на фоні (запис екрана, горизонтальне відео у вертикальному ролику) | `"cover"` |
| `base.zoom` | джамп-кати: на кожній склейці план 1.0 ↔ 1.1 + повільний наїзд | `true` |
| `duration` | тривалість основи, с (ставить `edit.mjs`) | `35.7` |
| `background` | фон під роликом з ідеї, під рамкою й фінальною карткою (10 фонів — `docs/ANIMATIONS.md`) | `"blobs"` |
| `words` | слова з таймінгами (ставить `edit.mjs`; для виправлення помилки розпізнавання — правиш `text`) | — |
| `captions` | стиль субтитрів (`docs/SUBTITLES.md`) або `false` | `{ "preset": "pop" }` |
| `keywords` | слова, що підсвічуються акцентом (за початком слова, без регістру) | `["гроші", "безкоштовно"]` |
| `events` | події на екрані (`docs/ANIMATIONS.md`) | див. нижче |
| `transitions` | переходи: `{ "at": 9.0, "type": "zoom" }`, типи `zoom` · `flash` · `whip` · `shake` · `blur` | — |
| `music` | `{ "src": "music/house-vibez.mp3", "volume": 0.06 }` або `null` | — |
| `sfx` | автоматичні звуки на події й переходи | `true` |
| `cover` | обкладинка (перші 8 кадрів + `cover.png`): `{ "title": "3 ПОМИЛКИ", "sub": "у рілсах", "frame": 2.5 }` (`frame` — секунда запису для тла) | — |
| `end` | фінальна картка після ролика: `{ "title": "Підпишись", "sub": "нові уроки щотижня", "dur": 2.5 }` або `null` | — |
| `brand` | перевизначити бренд лише для цього ролика: `{ "accent": "#00C2FF" }` | — |

## Приклад (монтаж запису, фрагмент)
```json
{
  "format": "9x16",
  "base": { "kind": "video", "src": "media/cut.mp4", "fit": "cover", "zoom": true, "segments": [{ "at": 0, "dur": 4.2 }, { "at": 4.2, "dur": 6.1 }] },
  "duration": 35.7,
  "background": "blobs",
  "words": [{ "text": "Я", "start": 0.1, "end": 0.2 }],
  "captions": { "preset": "classic", "position": "bottom" },
  "keywords": ["chatgpt", "безкоштовно"],
  "events": [
    { "type": "logo", "at": 1.3, "src": "logos/openai.svg", "label": "ChatGPT", "pos": "right" },
    { "type": "counter", "at": 1.9, "dur": 1.9, "from": 0, "to": 1000, "label": "таких відео" },
    { "type": "list", "at": 10.2, "dur": 5.9, "title": "Що можна", "items": ["Субтитри", "Квадрат, ромб, коло", "Будь-який кут"], "times": [10.2, 11.6, 13.8] },
    { "type": "subscribe", "at": 33.0, "dur": 2.4 }
  ],
  "transitions": [{ "at": 9.0, "type": "zoom" }, { "at": 24.1, "type": "whip" }],
  "music": { "src": "music/house-vibez.mp3", "volume": 0.06 },
  "sfx": true,
  "cover": { "title": "МОНТАЖ НЕЙРОНКОЮ", "sub": "без програм" },
  "end": { "title": "Підпишись" }
}
```

## Як розставляти події (порядок думки)
1. Прочитай транскрипт цілком. Знайди: **хук** (перші 2–3 с), **числа**, **переліки**, **порівняння**, **назви сервісів/брендів**, **емоції**, **заклик**.
2. На кожне — одна подія на своєму слові:
   - назва сервісу → `logo` (логотип з `studio/public/logos` або `tools/logos`; немає — знайди офіційний і поклади в `studio/public/logos`);
   - число → `counter`; «три кроки», «по-перше…» → `steps` / `list` з `times` на слова кожного пункту;
   - «було / стало», «так / ні» → `compare`; дані, ріст → `chart`;
   - емоція, предмет → `icon` (230 штук: `studio/public/assets/fl-<назва>.png`) або `sticker` людини;
   - головна думка → `title` (1–3 слова); «підпишись» → `subscribe`; імʼя експерта на початку → `lowerThird`;
   - «ось тут», «натисніть» на записі екрана → `callout` зі стрілкою;
   - свій приклад людини (фото/відео з `ЗАНЕСИ-СЮДИ/4…`) → скопіюй у `media/` і `image`.
3. Переходи: `zoom` або `whip` на зміну думки («але», «дивіться», «і головне»), `flash` — максимум 1–2 на ролик.
4. Перевір: між подіями є «повітря» (≥ 0.3 с), великі вставки не стоять підряд довше 6 с, у перші 3 с щось відбувається.
5. `render.mjs --draft` → `sheet.jpg` → виправ → фінал.
