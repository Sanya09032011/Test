# Субтитри

Автоматично з розпізнаного мовлення (запис) або з озвучки (ролик з ідеї), слово в слово по часу.
Подивитися всі стилі: `ДЕМО/ДЕМО-субтитри.mp4`, шрифти — `ДЕМО/ДЕМО-шрифти.png`.

У `edit.json`:
```json
"captions": { "preset": "box", "font": "Unbounded", "color": "#FFFFFF", "accent": "#00E0FF", "size": 64, "position": "bottom", "upper": true, "maxWords": 3, "stroke": true },
"keywords": ["безкоштовно", "гроші"]
```

| Поле | Значення |
|---|---|
| `preset` | `classic` (обведення + поточне слово кольором, як CapCut) · `pop` (слово вистрибує) · `karaoke` (сказане заливається кольором) · `box` (плашка їде за голосом) · `typewriter` (друкується по літерах) · `minimal` (спокійно, для експертів) · `hormozi` (1–2 великі слова, яскраво) · `neon` (світіння) |
| `font` | `Montserrat` · `Inter` · `Rubik` · `Unbounded` · `Manrope` · `Oswald` · `RobotoCondensed` · `Nunito` · `Comfortaa` · `Caveat` (рукописний) · `Pacifico` (каліграфія). За замовчуванням — шрифт бренду |
| `color` | колір звичайних слів (HEX) |
| `accent` | колір ключових/поточних слів (за замовчуванням — акцент бренду) |
| `size` | розмір у px (кадр 720 завширшки): 50 — дрібно, 64 — норма, 80 — великі. Довгий рядок сам зменшується, щоб влізти |
| `position` | `bottom` (над кнопками соцмереж) · `middle` · `top` · або число — Y центру рядка в px |
| `upper` | `true` — ВЕЛИКИМИ ЛІТЕРАМИ |
| `maxWords` | скільки слів у рядку (1–5) |
| `stroke` | обведення літер (краще читається на будь-якому тлі) |
| `keywords` | слова, що підсвічуються акцентом |

**Поради:** у говорящій голові субтитри під підборіддям — перевір на `sheet.jpg`, що рядок не перекриває рот
(інакше `position: 960` чи інше число). Помилка розпізнавання (ім'я, бренд) — виправ `text` цього слова в `edit.json → words`.
Назви сервісів пиши правильно латиницею (ChatGPT, CapCut), навіть якщо розпізналось кирилицею.
