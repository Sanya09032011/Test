# Ролик з ідеї (голосовий запит → готове відео)

Людина каже (або диктує голосом: Windows `Win + H`, macOS двічі `Fn`): «Зроби ролик про те, як…». Запису немає —
ролик складається з озвучки (ElevenLabs), субтитрів, анімацій, іконок, стікерів і фону.

## Кроки
1. **Уточни мінімум** (одним повідомленням, якщо не сказано): для кого ролик, головна думка, заклик у кінці, тривалість (15–40 с).
   Матеріали людини (текст, факти, картинки) — у `ЗАНЕСИ-СЮДИ/4…`: бери факти тільки звідти або з того, що людина сказала.
2. **Проєкт:** `node scripts/new.mjs <назва>`.
3. **Сценарій** → `script.json` у папці проєкту:
   ```json
   { "lines": ["[excited] Ви досі витрачаєте три години на один рілс?", "[confident] Дивіться, як це зробити за пять хвилин.", "…", "[warm] Підписуйтеся, щоб не пропустити."], "speed": 1.05 }
   ```
   Структура: **хук-біль** (перше речення — проблема глядача, не анонс) → 2–4 короткі кроки/факти → **заклик**.
   Речення по 4–9 слів, розмовно, на «ви». 15 с ≈ 35 слів, 30 с ≈ 70 слів.
4. **Перевірка тексту:** `node scripts/check-text.mjs <проєкт>` — без латиниці, цифр, тире й апострофів (усе словами: «Чат Джі Пі Ті», «пять», «двадцять відсотків»).
5. **Озвучка:** `node scripts/tts.mjs <проєкт>` → `media/voice.mp3` + `voice.json`. Перевір вимову: `node scripts/stt.mjs <проєкт> media/voice.mp3`.
   Неправильний наголос → додай слово в `library/voice/lexicon.json` і перегенеруй (див. `docs/VOICE.md`).
6. **Монтажний лист:** `node scripts/edit.mjs <проєкт> --style <стиль>`; фон підбери під тему (`docs/ANIMATIONS.md`).
7. **Події** — щільніше, ніж у монтажі запису (тут немає обличчя): нова подія кожні 1.5–3 с, на кожне ключове слово.
   Обовʼязково щось у перші 1.5 с (іконка болю, `title`, `counter`). Стікери людини (`studio/public/stickers`) — на емоціях.
8. **Чернетка → sheet.jpg → правки → фінал** (як у `docs/MONTAGE.md`, кроки 10–12).

## Горизонтальне відео для YouTube
`node scripts/edit.mjs <проєкт> --format 16x9` — усе те саме, кадр 1920×1080.
