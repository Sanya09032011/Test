# Ключ ElevenLabs і озвучка

## Що таке API-ключ і навіщо він
API-ключ — це «пароль для програм»: з ним наша система від твого імені звертається до сервісу ElevenLabs.
Він потрібен для двох речей:
- **розпізнати мову у твоєму відео** (звідси субтитри й вирізання пауз) — навіть якщо озвучку ти не робиш;
- **озвучити текст** голосом для роликів з ідеї.
Ключ — як пароль від банку: нікому не показуй, не публікуй, не надсилай у чати. Він зберігається лише у файлі `.env` на твоєму компʼютері.

## Як отримати (5 хвилин)
1. Зареєструйся на **elevenlabs.io** (для початку вистачить безкоштовного плану; клон власного голосу — від тарифу Starter).
2. Зліва внизу → профіль → **Developers** (або Settings) → **API Keys** → **Create API Key** → дай назву → **Create** → **Copy**.
3. Агент сам відкриє тобі файл `.env` — встав ключ після `ELEVENLABS_API_KEY=` (без пробілів і лапок) і збережи (`Ctrl + S`, на Mac `Cmd + S`).
4. Агент перевірить: `node scripts/doctor.mjs` → «ключ працює».

## Голос
- **Свій голос (найкраще для впізнаваності):** ElevenLabs → Voices → Add a new voice → **Instant Voice Clone** → завантаж 1–3 хв чистого запису свого
  голосу (без музики, тиха кімната) → Create. Відкрий голос → **Copy voice ID**.
- **Готовий голос з бібліотеки:** Voices → **Voice Library** → фільтр «Ukrainian» → послухай → Add → у своїх голосах **Copy voice ID**.
- ID встав у `.env` після `ELEVENLABS_VOICE_ID=`.

## Щоб озвучка не звучала як робот
1. **Пиши так, як говориш:** короткі речення, розмовні слова, звертання на «ви». Не «Даний інструмент дозволяє», а «Дивіться, що він уміє».
2. **Емоційні теги в квадратних дужках** перед реченням: `[excited]`, `[confident]`, `[warm]`, `[curious]`, `[playful]`, `[sarcastic]`, `[serious]`, `[whispers]`, `[laughs]`.
   Міняй тег кожні 1–2 речення — інтонація оживає.
3. **Розділові знаки = паузи:** кома — коротка, крапка — довша, трикрапка — задумлива. Знак питання й оклику змінюють інтонацію.
4. **Усе словами:** цифри («двадцять пять»), назви латиницею («Кеп Кат», «Чат Джі Пі Ті»), без тире й апострофів («пять», «обєкт»).
   Перевірка: `node scripts/check-text.mjs <проєкт>`.
5. **Наголоси:** неправильно наголосило — постав знак наголосу після голосної прямо в тексті (`за́мок` / `замо́к`)
   або додай слово в `library/voice/lexicon.json`: `"пісень": { "accent": "пісе́нь" }` — тоді виправиться в усіх наступних роликах.
6. **Налаштування в `script.json`:** `"stability": 0.3` (нижче — живіше, вище — рівніше), `"style": 0.45`, `"speed": 1.05` (0.7–1.2), `"tempo": 1.1` (пришвидшити готовий звук без зміни тембру).
7. **Модель:** `eleven_v4` (за замовчуванням у `.env`) — дешевша й розуміє теги. Інша — `ELEVENLABS_MODEL` у `.env` або `"model"` у `script.json`.
8. Перевірка на слух обовʼязкова: машина не завжди чує неправильний наголос. Прослухай `media/voice.mp3` перед монтажем.
