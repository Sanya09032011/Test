# AI-Монтажер

Нейронка монтує твої рілси й відео для YouTube. Записав розмовне відео на телефон → кинув у папку → сказав «змонтуй» →
отримав ролик із субтитрами, музикою, звуками, анімаціями, інфографікою, своїми стікерами й динамічними переходами.
Або просто надиктував ідею — і отримав готове відео з озвучкою.

**Почати:** `ПОЧНИ-ТУТ.txt` (Claude) або `КОДЕКС-ПОЧНИ-ТУТ.txt` (ChatGPT / Codex) — 3 кроки: увімкнути автоматичний режим (і плагін Remotion), вставити шлях до папки й готове повідомлення, Enter.

## Що вміє
- **Монтаж запису в один запит:** прибирає паузи, «е-е», «м-м» і невдалі дублі; чистить звук; джамп-кати.
- **Автосубтитри:** 8 стилів, 11 шрифтів з кирилицею, свій колір, розмір, позиція й анімація тексту.
- **Візуалізація сказаного:** на кожне число, перелік, назву сервісу чи емоцію — анімація на своєму слові.
- **Ролик з ідеї:** сценарій → озвучка ElevenLabs (свій голос або з бібліотеки) → готове відео.
- **Бренд-лук:** твої кольори й шрифт у кожному ролику; картка персонажа, персонаж у будь-якому стилі, власний стікерпак (фон прибирається автоматично).
- **Формати:** рілси 9:16 (Instagram, TikTok, Shorts) і YouTube 16:9, 1080p, гучність під соцмережі, обкладинка.
- **Кілька роликів за раз:** кинь 10 відео — змонтує по черзі, поки ти в магазині.

## Бонуси
- **10 готових анімацій:** плашка з іменем, велике слово, лічильник, стрілка-виноска, список, кроки, інфографіка, було/стало, сповіщення, кнопка «Підписатися» — `ДЕМО/ДЕМО-анімації.mp4`.
- **10 анімованих фонів:** клітинка, крапки, градієнт, плями, смуги, прожектор, хвилі, вогники, промені, неон — `ДЕМО/ДЕМО-фони.mp4`.

## Що всередині
| Папка | Що там |
|---|---|
| `ЗАНЕСИ-СЮДИ/` | куди кидати свої файли (запис, бренд і стікери, референси, картинки, музика) |
| `projects/` | твої ролики (кожен у своїй папці) |
| `studio/` | «монтажний стіл» (Remotion): шаблон ролика, стилі, анімації, фони, іконки, звуки, музика |
| `scripts/` | інструменти, які запускає нейронка (нарізка, субтитри, озвучка, рендер, стікери) |
| `docs/` | довідники: монтаж, ролик з ідеї, субтитри, анімації, бренд і стікери, референси, озвучка, музика |
| `tools/logos/` | ~950 логотипів сервісів |

Потрібно: компʼютер з Windows або macOS, застосунок Claude (Pro) або ChatGPT з Codex, акаунт ElevenLabs (є безкоштовний план).
Звідки музика, звуки й іконки — `studio/public/ATTRIBUTION.md`.
